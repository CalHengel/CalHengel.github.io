## Description of Assignment

For this assignment, I created a code using the Arduino software for the LilyPad USB Plus that uses two boolean variables called btn and swt that simulate a button and switch. We have not used them physically yet so we change their values within the code. Depending on whether btn or swt were true or false, would determine what LED would turn on. In my code I used logical operators and if/else if statements for the different combinations used. 

## Nested Conditionals or Logical Operators?

For this assignment I used logical operators because there were only two boolean variables used in the code and only four different possible combinations. This made more sense for me to use because it made it easier to read the code and check both variables instead of using nested if statements that may be unnecessary and harder to read. 

## Tip/Hint to Give Past Self on This Deliverable

A tip I would give my past self is to make and have a table with me that has the four different possible combinations for the btn and swt variables. This way it will make it easier to keep track of which LED should be on for its respective combination.
